# Archivo histórico

Este directorio contiene material no utilizado por la compilación ni por la ejecución de la aplicación.

## Contenido

- `legacy-resources/`: planos y configuración anteriores, conservados solo como referencia.
- `ui/app.js.orig`: instantánea previa del frontend, excluida del ensamblado.
- `docs/historical/`: cierres y changelogs de entregas anteriores.

No colocar aquí código C#, XAML, recursos actuales ni datos operativos sin actualizar el proyecto y su documentación.

## Evidencia archivada adicional

- `releases/`: paquete RC M10 conservado como evidencia de entrega; no se usa para compilar.
- `audits/map-alignment/`: scripts y resultados de una auditoría puntual de alineación; el perfil temporal de Chromium fue eliminado por ser caché regenerable.
- `docs/historical/tasks/`: planes de rediseño completados; los contratos y procedimientos activos permanecen en `tasks/`.
